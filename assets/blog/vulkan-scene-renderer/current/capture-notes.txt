CURRENT NATIVE CAPTURES — 7 NOVEMBER 2026

sponza-daylight.jpg / sponza-arcade.jpg
bim-tekla-native-ifc.jpg / bim-tekla-detail.jpg
  Native 1920x1080, progressive reference path tracing, 512 samples per pixel,
  eight bounces, OptiX display denoising and native AgX display grading.
  Sponza and Tekla use the Citrus Orchard Road (Pure Sky) environment.

a-beautiful-game.jpg / a-beautiful-game-detail.jpg
  Native 1920x1080, forward PBR, TAA, 1x MSAA, two rectangular studio area
  lights, sampled soft ray-query shadows, native AgX grading and the original
  2048x2048 textures. Aerodynamics Workshop supplies fill and reflections.
  The scene's solid glass produces unsupported paths in the current reference
  tracer; these chess views use forward rendering.

All six images were captured by the renderer on an NVIDIA GeForce RTX 2080 SUPER.
The JPEG sources were encoded at quality 93 from native PNG captures with the
complete frame preserved. JPEG is lossy; there is no cropping, resizing of the
captured frame, retouching, compositing, generated content or image relighting.
The site's optional WebP card is a separately encoded, smaller-file derivative
of its source JPEG; it preserves the full 1920x1080 frame and composition.

The capture builds included local source changes before the merge. The merge
revision is a permanent location for the records, not an assertion that every
image was captured from an identical clean Git checkout. Per-image executable,
SPIR-V/runtime, input, native PNG and JPEG hashes identify the actual captures.
The published v0.2.0-taa-preview remains an older release; these images do not
claim that the newer work was published in that preview.
